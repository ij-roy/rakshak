## [1.0.0] — 2026-09-23

### Added

- Monorepo foundation (pnpm workspaces) for Expo Android + Next.js web.
- Shared deterministic simulation (`game-core`) and validated content (`game-data`).
- Versioning constants: game `1.0.0`, content `1.0.0`, save schema `1`.
- Implementation status and decisions log under `docs/`.
